# E-commerce Sales and Customer Behavior Analysis

This is my first SQL + Python data analysis portfolio project.

## Goal

Analyze an e-commerce dataset to understand revenue trends, customer behavior, and product performance.

## Tools

- SQL
- Python
- pandas
- matplotlib / seaborn
- Jupyter Notebook

## Business Questions

1. Which product categories generate the most revenue?
2. Which customers or regions contribute the most sales?
3. How do sales change over time?
